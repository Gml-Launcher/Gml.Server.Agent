# Gml.Launcher & Gml.Server.Agent

Репозиторий содержит компоненты экосистемы **Gml.Launcher** — современного, высокопроизводительного решения для создания собственных игровых проектов Minecraft. 

Центральной частью серверной автоматизации в этой экосистеме является компонент **Gml.Server.Agent**.

## 🛠 Что такое Gml.Server.Agent?

**Gml.Server.Agent** — это специализированный легковесный сервис (агент), предназначенный для управления, мониторинга и оркестрации игровых серверов Minecraft. Вместо того чтобы вручную управлять процессами Java, агент берет эту рутину на себя.

### Основные функции агента:
* 🚀 **Управление жизненным циклом:** Удаленный запуск, остановка и перезапуск игровых серверов (Vanilla, Paper, Fabric, Forge и др.).
* 📊 **Мониторинг ресурсов:** Сбор метрик в реальном времени (потребление процессора, оперативной памяти, аптайм).
* 📁 **Синхронизация файлов:** Автоматическое развертывание сборок, обновление модов, плагинов и конфигурационных файлов.
* 💬 **Удаленная консоль:** Перенаправление потоков ввода-вывода (стандартной консоли Minecraft) для удаленного администрирования.

## 🔗 Интеграция с Gml.Launcher

`Gml.Server.Agent` не является изолированным продуктом — он **нативно интегрирован в основной проект Gml.Launcher** (в его серверную часть `Gml.Web.Api` / `Gml.Backend`).
